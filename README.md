<h2>🧐 Features</h2>

Here're some of the project's best features:

*   Facial Recognition Login for secure access
*   Voice Commands using Azure Speech to Text
*   Smart Replies powered by Gemini AI
*   Text-to-Speech responses using AWS Polly
*   User Authentication & Access Control
*   Live Webcam Integration
*   Real-Time Face Verification via AWS Rekognition
*   Facial-Based Registration System
*   Responsive Web Interface (built with React + Three.js)
*   Multimodal AI Support (voice + facial + text)

<h2>🛠️ Installation Steps:</h2>

<p>1. Step 1: Clone the Repository</p>

```
git clone https://github.com/SaiHarsha9992/Vikram-Ai-Assistant.git cd vikram-ai-assistant
```

<p>2. Step 2: Install Backend Dependencies</p>

```
npm install
```

<p>3. Step 3: Start the Backend Server</p>

```
npm start
```
